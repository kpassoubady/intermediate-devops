# Intermediate DevOps

Primary (internal) repository for the Intermediate DevOps instructor-led course: a hands-on introduction to CI/CD pipelines in Harness, infrastructure as code, credential management, Docker, and Kubernetes deployments.

This repo holds the catalog, outlines, slides, diagrams, demos, and research notes. It is not distributed to students; only exported artifacts (for example, slides as PDF) go out.

## Contents

- `devops-demos/`: existing demo, lab, and slide material, including `catalog/Intermediate-DevOps-Outline.docx.md` (course outline).
- `llm-context/`: context for LLM agents.
- `scripts/`: build and export helpers.
