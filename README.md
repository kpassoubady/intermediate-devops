# Intermediate DevOps

Primary (internal) repository for the Intermediate DevOps instructor-led course: a hands-on introduction to CI/CD pipelines in Harness, infrastructure as code, credential management, Docker, and Kubernetes deployments.

This repo holds the catalog, outline, slide sources, quizzes, and research notes. It is not distributed to students. Learner material (labs, app, solutions, catch-up scripts, released slide PDFs) lives in the companion repo, [intermediate-devops-companion](https://github.com/kpassoubady/intermediate-devops-companion).

## Contents

- `devops-demos/catalog/`: course catalog and outline (`Intermediate-DevOps-Outline.md`).
- `devops-demos/slides/`: Reveal.js decks for Day 1 to Day 3 (`day1.html` to `day3.html`).
- `devops-demos/quizzes/`: quizzes for each day.
- `docs/`: instructor guides.
- `llm-context/`: context for LLM agents.
- `scripts/`: build and export helpers.
